# ymawky Architecture & Implementation Summary

**ymawky** — "yuh maw kee" — a static-file web server written entirely in hand-rolled ARM64 (AArch64) assembly for macOS and Linux. No libc, syscall-only, single-process (no fork). Serves **HTTP/1.1** and **HTTP/2** (RFC 9113). All content is embedded into the binary at build time — there are no filesystem reads for request serving. GPL-3.0.

> This document describes the current tree. Features from earlier versions (PUT, DELETE, CGI, directory listing, fork-per-connection) were removed — see the git history for those. Anything referenced here can be found in `src/`; the per-function files carry their own doc headers.

---

## Build & Link Model

- **Build**: `Makefile` compiles every `src/**/*.S` (recursively — one file per function, grouped in module folders) into `.o` via `cc -g -c`, then links with `ld -l System -e _main -arch arm64` (macOS). The `www/` tree is embedded first by `embed_www.sh` → `src/embedded.S` (see below).
- **Entry point**: `_main` on macOS, `_start` on Linux — no libc symbols are called, only raw `svc` syscalls (`svc #0x80` on macOS, `svc #0` on Linux).
- **Relocation**: Mach-O `@PAGE`/`@PAGEOFF` on macOS, ELF `:pg_hi21:`/`:lo12:` on Linux, behind the `adr_l`/`ldr_l`/`str_l` macros in `defs.S`.
- **Platform split**: `defs.S` `#ifdef __linux__` picks syscall numbers, the `SCWINUM`/`SCWISVC`/`SCERR` macros (Linux `SCERR` converts negative errno → positive + carry), `SO_*`/`O_*` constants and `stat`/`dirent` offsets per platform.

## Source File Map

The assembly is split one function per file, grouped into module folders under `src/`. Every function file carries a standard documentation header (Function Name / Description / Input / Output / Clobbered Registers / Stack Usage). Shared per-module data lives in a `data.S` next to the functions; the shared headers below stay at the root.

## Startup & Main Loop (`src/ymawky/main.S:_main`)

1. **Argument parsing**: If `argc > 1`, inspects `argv[1][0]`. If `< 'A'` (numeric), parses as port via `atoi` and overwrites the `addr` struct's port field (big-endian `rev16`). If `>= 'A'`, sets `x28=1` — a vestigial "debug" flag that is never read again (there is no fork to disable).
2. **Socket setup**: `socket(AF_INET, SOCK_STREAM, 0)` → `setsockopt(SO_REUSEADDR)` → `bind(addr:16)` → `listen(5)`. Binds `0.0.0.0` on Linux, `127.0.0.1` on macOS.
3. **Signal setup**: `SIGCHLD` → `SIG_IGN` (with `SA_NOCLDWAIT` on Linux) and `SIGPIPE` → `SIG_IGN` so `write()` returns `EPIPE` instead of killing the process. (Legacy of the fork era; kept for safety.)

### Accept Loop

```
loop:
  accept(sockfd, NULL, NULL) → clientfd
  b child        ← single process, connection handled inline (no fork)
```

`child_end` closes the client fd and **branches back to `loop`** — one process serves every connection sequentially.

## Connection Handling (`child`, `src/ymawky/child.S`)

1. **Socket options**: `SO_RCVTIMEO` (from `RECV_TIMEOUT`, a `struct timeval`) on the client fd; macOS additionally sets `SO_NOSIGPIPE`.
2. **Read loop**: `read(clientfd, buf+offset, BUF_SIZE-offset)`, cumulative byte count in `x7`. On the **first** read, `h2_probe(buf, x7)` checks whether the buffered bytes are the HTTP/2 client connection preface prefix:
   - **Yes → HTTP/2**: `h2_connection_loop(clientfd, buf, x7)` takes over and serves the whole connection; when it returns, `child_end`.
   - **No → HTTP/1**: `parse_header_end` finds `\r\n\r\n`. Exits on `\r\n\r\n` found, 431 if the buffer fills, 400 if the header never completes, silent close on network errors (`ECONNRESET`, `ECONNABORTED`, `EPIPE`, `ENET*`, `EHOST*`), 408 on `ETIMEDOUT`, 500 otherwise.
3. **Log to stdout**: prints `\n\n<<<\n` + the header, records `req_start` (gettimeofday).
4. **`verify_http_version`**: accepts `HTTP/1.1` (must carry a `Host:` field, checked via `get_header_field`) and `HTTP/1.0`; anything else 400, bare `HTTP/` 505.
5. **`parse_request`**: fills the protocol-neutral `request` struct (see below); failure → 400.
6. **Method dispatch** on `REQ_METHOD`: `GET` → `get`, `HEAD` → `head`, `OPTIONS` → `options`, `BREW` → 418, anything else → 501.

`child_end` (`src/ymawky/child_end.S`) records `req_end`, prints `Took: Nµs` via `log_timing`, closes `clientfd` (and `file_des` if it is not -1), and branches back to `loop`.

## The protocol-neutral seams (`src/data.S`, offsets in `src/defs.S`)

The architecture funnels both protocols through two fixed-layout structs:

- **`request`** (`REQ_*`): `REQ_METHOD` (GET_ID/HEAD_ID/OPTIONS_ID/BREW_ID/UNKNOWN_ID), `REQ_PATH` (docroot-prefixed, percent-decoded), `REQ_PATH_LENGTH`, `REQ_QUERY`/`REQ_QUERY_LENGTH`, `REQ_AUTHORITY` (Host/`:authority` value, NUL-terminated copy in `authority_buf`), `REQ_STREAM_ID` (0 for HTTP/1), `REQ_RANGE_PTR`/`REQ_RANGE_LEN`, `REQ_FORBIDDEN`. Filled by `parse_request` (HTTP/1) or `h2_build_request` (HTTP/2).
- **`response`** (`RESP_*`): `RESP_STATUS`, `RESP_CONTENT_TYPE`/`_LEN`, `RESP_CONTENT_LENGTH`, `RESP_BODY`/`RESP_BODY_LENGTH`, `RESP_RANGE_START`/`RESP_RANGE_END` (-1 = no range). Filled by `create_response`; consumed by `http1_write_response` (HTTP/1) and `h2_write_headers`/`h2_write_body` (HTTP/2).

## The transport seam (`src/transport/`)

Every byte the HTTP/2 engine exchanges with a client flows through two
functions (PLAN.MD §1.2-§1.3): `transport_read` (wrapped by
`h2_read_exact`) and `transport_write` (wrapped by `write_all`). Both
dispatch on the runtime global `transport_mode` (`src/transport/data.S`):

- `TRANSPORT_PLAIN` (the default, from `config.S:TRANSPORT_MODE`) — the
  raw socket `read`/`write` syscall path, behaviour unchanged.
- `TRANSPORT_TLS` — not implemented yet; both sides fail closed with
  `ENOTSUP` + carry set, so a TLS-mode connection can never exchange
  plaintext. Later phases replace the stub with the TLS record layer.

The mode is a runtime global initialised from the compile-time default,
so a future startup switch can select TLS without recompiling.

---

## TLS 1.3 (`src/tls/`, constants in `src/defs.S`)

The TLS work (PLAN.MD Phase 2+) is data-only so far. `defs.S` carries
the wire-format constants — protocol versions, cipher suites, named
groups, signature schemes, record/handshake/alert/extension types, the
handshake state machine — and the `tls_state` field offsets. `src/tls/data.S`
holds the per-connection state block:

- `tls_state` — one block per connection (a connection handler is one
  process, so the global is per-connection, like `request`/`response`):
  fd, handshake state, client/server randoms and key shares, shared
  secret, transcript hash, handshake/master secrets, the four
  AES-128-GCM traffic keys + IVs, record sequence numbers, and the
  negotiated ALPN name. Every field is exported under a `tls_*` label
  so `tests/unit/test_tls.c` can verify each sits at exactly the
  `TLS_*` offset in `defs.S`.
- `tls_alpn_h2` — the `"h2"` ALPN identifier (RFC 7301) this server
  will negotiate.

Covered by `tests/unit/test_tls.c` (constant values, field offsets,
16-byte alignment, storage extent, initial values).

## Path Handling (`src/parse/parse_path.S`)

Called by `parse_request` for every parsed method. Pipeline:

1. **`parse_path`**: Scans the first 16 bytes for ` /` (space+slash) or ` *` (space+asterisk) — the space guard avoids matching `HTTP/1.1`. Copies the path into `filename_buf` prefixed with `DOCROOT` (`www/`), collapses consecutive slashes, splits `?query_string` into `query_buf`. An empty path appends `DEFAULT_FILE` (`index.html`) for GET/HEAD; `*` becomes the one-byte path `*`.
2. **`decode_url`**: In-place `%XX` hex decoding (lowercases hex digits). Rejects `%00` (NULL byte) and bad/truncated escapes → parse failure (400). Runs **before** the traversal check so `%2e%2e%2f` decodes to `../` and is caught.
3. **`check_path_safety`**: All bytes must be printable ASCII (0x20–0x7E).
4. **`check_path_traversal`**: Rejects a path segment that is exactly `..` (dots-only segment of length 2); `foo..txt` and `...` are fine.
5. **Authority**: `get_header_field("Host")` value is copied into `authority_buf` as `REQ_AUTHORITY`.

## The embedded asset model (`embed_www.sh`, `src/file/lookup_embedded.S`)

There is **no filesystem access at request time** — every byte served comes from an embedded table.

- **Build-time (`embed_www.sh`)**: recursively finds `www/` files, determines MIME by extension, **gzip-compresses text-like files** (html/htm/css/csv/xml/js/json/mjs/map/svg/txt/ttf/otf) when the result is smaller (cache in `www_gz/`), computes a **SHA-256 ETag** of the served bytes, and an FNV-1a hash of the path. Generates `src/embedded.S` with `.incbin` payloads and an 80-byte-per-entry table (hash, path ptr/len, content ptr/size, content-type ptr/len, gzip flag, ETag ptr/len), plus a hash-sorted index table. Regenerated by `make assets` when any `www/` file changes.
- **Runtime (`lookup_embedded(path, len)`)**: currently a linear scan over the (lexicographically sorted) `embedded_files` table; returns content pointer/size, content-type ptr/len, gzip flag and ETag ptr/len, with carry set on miss. Returns into the `embedded_*` globals via the callers.
- Serves `Content-Encoding: gzip` and `ETag` headers automatically for gzipped/ETagged assets.

## HTTP/1 method handlers

### `get_setup` (shared by GET and HEAD)
- Reads `REQ_PATH`; `*` → 400.
- `lookup_embedded(REQ_PATH, REQ_PATH_LENGTH)`: found → fills the `embedded_*` globals, sets `resource_type = RES_EMBEDDED`, `file_des = -1`, returns (content_size, `S_IFREG`). Not found → 404.

### `get` (`src/http1/get.S`)
- `get_setup` → file length; `parse_range` on the request header:
  - `bytes=X-N` (concrete): clamps end to `size-1`; 416 if start ≥ size or the file is empty.
  - `bytes=-N` (suffix): empty file → serve whole file as 200; `N ≥ size` → whole file; otherwise start = `size - N`.
  - `bytes=X-` (open-ended): end = `size-1`; 416 if start ≥ size.
- Builds the body window `[start..end]` into `embedded_content`, then `create_response(response, 200|206, size, range_start, range_end, body, body_len)` → `http1_write_response` → `child_end`. Unsatisfiable ranges → 416, encoder failure → 500.

### `head`
`get_setup` then `create_response(200, size, no range, body ptr, body_len 0)` — headers only; `Content-Length` still reflects the full resource — → `http1_write_response` → `child_end`.

### `options`
`*` → 204; `lookup_embedded(REQ_PATH)` found → 204; not found → 404. (No stat, no 403 path in use.)

## Response System

### `create_response` (`src/http1/create_response.S`)
Fills the `response` struct from arguments + the `embedded_*` globals and records `response_code` for the timing log. Content-type comes from `embedded_ct` when present, else `get_filetype(REQ_PATH)`.

### `http1_write_response` (`src/http1/http1_write_response.S`)
Builds the header in `header_buf` (`RESPONSE_HEADER_SIZE`, overflow → carry set → caller replies 500):
1. Status line via `find_http_code` (falls back to a hardcoded 500 string).
2. `Content-Length: N` — `end-start+1` for a ranged response, else the total; skipped for 204.
3. `Content-Range: bytes start-end/total` for 206.
4. `Content-Type` (skipped for 204 or empty resources).
5. `Content-Encoding: gzip` when the embedded resource is gzipped; `ETag` when a precomputed hash exists.
6. Fixed tail: `Connection: close`, `X-Frame-Options: DENY`, `Referrer-Policy: no-referrer`, `Allow: GET, HEAD, OPTIONS`, `Accept-Ranges: bytes`, `Server: ymawky`.
7. **One `writev`** (zero-copy): `header_buf` + body as two iovecs; write errors are ignored (the connection is closing anyway).

### `reply_status(code, ret)` (`src/http1/reply_status.S`)
Serves error responses. Assembles `ERR_DIR + code + ".html"` in `err_page_buf` and looks it up in the embedded table — no filesystem open. Found → `create_response` + `http1_write_response` with the page body; not found (or code < 400 / > 507) → header-only. Logs `\n\n>>>\n` + the header to stdout. If `ret == 0` branches to `child_end`; if nonzero returns (unused by the current tree).

### `find_http_code` (`src/http1/find_http_code.S`)
Linear scan of `status_table` (24-byte entries: status, string ptr, length). Contains: 200, 201, 204, 206, 400, 403, 404, 408, 409, 411, 413, 414, 416, 418, 431, 500, 501, 502, 503, 505, 507. Note: 201/409/411/413/502/503/507 are **unreachable leftovers** from the removed PUT/CGI/process-limit features; the current handlers only ever produce 200/204/206/400/403/404/408/414/416/418/431/500/501/505.

### `handle_fs_error` (`src/http1/handle_fs_error.S`)
Still present but **has no callers** — dead code from the pre-embedded filesystem era.

## HTTP/2 (`src/h2/`, `src/hpack/`)

RFC 9113 + RFC 7541. Protocol detection and the transport boundary are documented in [`docs/TRANSPORT_AUDIT.md`](TRANSPORT_AUDIT.md).

- **Entry**: `child` → `h2_probe` (preface-prefix match) → `h2_connection_loop(fd, buf, buffered)` (`src/h2/h2_connection_loop.S`).
- **Connection loop**: finishes verifying the 24-byte preface (via `h2_read_exact`), sends the opening SETTINGS frame (`h2_send_settings`), then loops: buffer a full 9-byte frame header → `h2_parse_frame_header` → `h2_validate_frame` → buffer the full payload → `h2_dispatch_frame`. Connection errors → GOAWAY; stream errors → RST_STREAM; timeout/EOF closes the connection. Per-connection state lives in `h2_conn` (`H2C_*` offsets in `defs.S`, storage in `src/h2/data.S`).
- **Frame handlers** (`h2_handle_*`): SETTINGS (incl. ACK), PING (ACK echoes the 8 octets), GOAWAY, HEADERS, DATA, RST_STREAM, PRIORITY, WINDOW_UPDATE.
- **Stream engine** (`h2_stream_create/find/event`): fixed 32-entry table (`H2_MAX_STREAMS`), RFC 9113 §5.1 states, per-stream flow-control windows (§5.2).
- **Request seam**: `h2_build_request` decodes the HEADERS HPACK block and fills the same `request` struct (method, path, query, authority, `REQ_STREAM_ID`) — `h2_process_request(stream_id, fd)` then resolves the resource exactly like the HTTP/1 handlers (embedded lookup) and encodes the response.
- **Response encoders**: `h2_write_headers` (HPACK-encodes `:status`/content-type/content-length/content-range/content-encoding into a HEADERS frame, one `write_all`), `h2_write_body` (DATA frames chunked to the flow-control windows; when credit runs out it reads + dispatches frames waiting for WINDOW_UPDATE), `h2_reply_status`, `h2_send_goaway`, `h2_send_rst_stream`, `h2_handle_ping` (ACK).
- **HPACK** (`src/hpack/`): static-table-only decoder (dynamic table disabled — the opening SETTINGS advertises `SETTINGS_HEADER_TABLE_SIZE = 0`), RFC 7541 Appendix A static table + Appendix B static Huffman decode (`h2_huffman_table.S`, generated).
- **Transport boundary**: every read goes through `h2_read_exact` (raw `SYS_read` loop) and every write through `write_all` (raw `SYS_write` loop) — the two choke points the TLS work (PLAN.MD §1.2) will sit behind.

## MIME Type Detection (`src/file/get_filetype.S`)

Fixed 96-byte-per-entry lookup table (`file_types_*`), grouped by the extension's first character for direct dispatch: extension (8 bytes, `.html\0`) + MIME string (88 bytes). Walks the filename backwards to the `.`, lowercases the next byte for group dispatch, then `streqn_i` (case-insensitive) within the group. Returns `text/plain; charset=utf-8` for unknown/missing extensions. 43 extensions across the web/image/font/document/video/audio/archive families.

## Utility Functions (`src/util/`)

- **`write_all(fd, buf, len)`**: Retry loop handling partial writes. Retries `EINTR`; treats `EPIPE` as a clean exit (carry clear); returns total bytes written, carry + errno on other failures.
- **`itoa(n)`**: Decimal digits into a static buffer; returns pointer + length.
- **`atoi(str)`** / **`atoi_n(str, len)`**: String→integer with a 19-digit overflow guard; carry set on error.
- **`memcpy(dst, src, len)`**, **`strlen(str)`**, **`streqn(a, b, maxlen)`** (exact), **`streqn_i(a, b, maxlen)`** (case-insensitive, OR-with-0x20).
- **`fnv1a_64`**: FNV-1a 64-bit hash — matches the path hashes `embed_www.sh` computes for the embedded lookup table.

## Header Parsing (`src/parse/`)

- **`parse_header_end(buf, len)`**: State-machine search for `\r\n\r\n`; returns the index one past the terminator (0 if not found). Handles false starts such as `\r\n\r>\r<\n\r\n`.
- **`get_header_field(buf, len, field, field_len)`**: Line-oriented scan for `Field: value\r\n` (case-insensitive `streqn_i`). Returns pointer to the value + remaining length; carry set if not found. Rejects lines starting with whitespace and fields not followed by `:`.
- **`parse_range(buf, len)`**: Finds `Range: bytes=...` and parses `X-N`, `-N`, `X-` forms; returns start/end (-1 for absent parts), carry set when no valid range.
- **`parse_request(buf, len)`**: The HTTP/1 → `request` struct parser (see "Connection Handling"); method detection via direct word compares (GET/HEAD/OPTIONS/BREW).
- **`parse_h2_path`**: HTTP/2 path/query splitter (fills the same `REQ_PATH`/`REQ_QUERY` fields from a decoded `:path`).

## Security Model

- **No filesystem at request time**: all content (including error pages) comes from the build-time embedded table; there is nothing to traverse, symlink, or read on the server disk.
- **Path confinement**: every request path is prefixed with `DOCROOT` (`www/`) and must match an embedded entry exactly — `/etc/passwd` becomes `www/etc/passwd` → 404.
- **Path traversal prevention**: per-segment `..` detection (`check_path_traversal`), after `%XX` decoding so encoded `..` is caught.
- **ASCII-only paths**: `check_path_safety` rejects control characters and non-ASCII bytes; `%00` is rejected by `decode_url`.
- **Slowloris mitigation**: `SO_RCVTIMEO` per-connection socket timeout (`RECV_TIMEOUT`, default 10s) — no data for 10s → 408.
- **Header limits**: buffer-cap 431 when `buf` fills without a header terminator; paths/query capped at 4096 bytes (414).
- **Unreachable leftovers**: `MAX_PROCS`/`proc_info` (fork-era process cap), `ALLOW_DIR_LISTING`, and `handle_fs_error` remain in the tree but are not exercised by any code path.

## Platform Notes (macOS vs Linux)

- **Syscall convention**: macOS `x16` + `svc #0x80`, carry set + errno in `x0` on error; Linux `x8` + `svc #0`, negative errno in `x0` (the `SCERR` macro normalises to positive + carry so `b.cs` works identically).
- **accept**: macOS `SYS_accept`; Linux `SYS_accept4` (flags 0).
- **SO_NOSIGPIPE**: macOS-only socket option set per connection; Linux relies on the ignored `SIGPIPE` + `EPIPE` from `write()`.
- **Signals**: macOS `sigaction` (with `sa_tramp`); Linux `rt_sigaction`.
- **Relocation**: `@PAGE`/`@PAGEOFF` (Mach-O) vs `:pg_hi21:`/`:lo12:` (ELF) behind the `adr_l`/`ldr_l`/`str_l` macros.
- Removed-with-the-features constants (`SYS_fork`, `SYS_setitimer`, `SYS_proc_info`, `SYS_renameatx_np`, `SYS_getdirentries64`, `O_NOFOLLOW_ANY`, `AT_SYMLINK_NOFOLLOW_ANY`, `SA_NOCLDWAIT`) still appear in `defs.S` but are unused.
